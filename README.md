This repository holds the suite overview for the BCP-008 series of AMWA Best Common Practices, part of the family of [Networked Media Open Specifications](https://specs.amwa.tv/nmos) from the [Advanced Media Workflow Association](https://amwa.tv).

<!-- INTRO-START -->

### What does the suite do?

- The BCP-008 series defines status-monitoring recommendations for NMOS Devices.
- It describes the status models and monitoring requirements for both stream Receivers and Senders.

### Why does it matter?

- Consistent status models allow monitoring systems and operators to identify connectivity, synchronization, and stream or essence problems in a predictable way.
- Separating the Receiver and Sender recommendations makes the requirements clear while keeping them part of one coherent status-monitoring suite.

### What are the recommendations?

- [BCP-008-01: NMOS Receiver Status Monitoring](https://specs.amwa.tv/bcp-008-01)
- [BCP-008-02: NMOS Sender Status Monitoring](https://specs.amwa.tv/bcp-008-02)

## Getting started

Start with the BCP relevant to the type of stream endpoint being monitored:

- [BCP-008-01](https://specs.amwa.tv/bcp-008-01) for Receivers
- [BCP-008-02](https://specs.amwa.tv/bcp-008-02) for Senders

There is more information about the NMOS Specifications and their GitHub repositories at <https://specs.amwa.tv/nmos>.
